# 角色：產生、接手、檢查點

為什麼要角色卡：session 沒有跨視窗記憶，ListAgents 名稱重開就變。卡把「這個角色做什麼、讀什麼」固定在專案裡，新 session 照卡接手。
卡在 `<主 repo>/.claude/office/roles/`（位置規則見 `SKILL.md`）。

## 1. 從規則產生角色（「照 <規則路徑> 設這個專案的角色」）

1. **讀規則**：只讀到分得出職責為止；大文件分段讀（Read 帶 `pages`）。
2. **在對話裡列提案表**（不寫檔）：

   | 角色 | 職責（一句） | 邊界：做／不做 | source（規則路徑＋章節） | 為什麼另開 session |
   |---|---|---|---|---|

   「為什麼另開 session」MUST 填下列其中一項（承接其他階段的主線角色填「主線」），填不出來的階段**併進別的角色**，不另外建卡——規則裡的每個階段不等於一個人（例：gstack 是一個 session 依序跑多個 skill）：

   | 判準 | 例 |
   |---|---|
   | 需要獨立觀點 | 審查、測試：做的人審自己看不出問題 |
   | 能平行做 | 不同模組、不同部門 |
   | 上下文會互相干擾 | 一邊讀大量規格、一邊寫程式 |

   規則指名「只有 X 能決定」的事（核可需求、放行發布…）是使用者或主管的權限，**不建卡**；在提案表下方列出「歸使用者／主管：…」。
3. **使用者改／核可**。🔴 建卡＝新建文件，只有使用者能核可。
4. **寫卡**（格式見 §2），一角色一檔。commit 由使用者決定。
5. **建卡跟開人分開**：建完不自動開 session；要開人走 `lead.md` §1 升層。

規則改版時：`grep -l "source: <規則路徑>" roles/` 找出要重新檢查的卡，提案改哪些，使用者核可再改。

## 2. 角色卡格式

```markdown
---
role: <角色名>
source: <規則路徑>#<章節標題原文>   # 多章節同一行用「、」接：flow.md#1. 需求、#6. 發布；手動建的寫「使用者指定」
layer: 1                     # 1 或 2
reports_to: 主管              # 第 1 層寫「主管」；第 2 層（小隊卡）寫「部門主管」
---
## 職責
一兩句。
## 邊界
- 做：…
- 不做：…（碰到就回報主管）
## 必讀
最多 5 份，路徑＋一句為什麼。
## 可用 skill
例：/review、/qa、wiki-ingest。沒有就寫「無」。
## 交付
交什麼、交給誰、放哪。
```

- **只放定義，不放進度**。誰持有、做到哪在 `collab.md`（主管寫）與 `checkpoints/`（持有者寫）。
- 持有者發現定義不對（必讀過時、邊界不合）→ 回報主管或使用者，不自己改。

## 3. 接手（「你是 <角色>，接手」）

1. 讀 `roles/<角色>.md`；專案沒有、派工單寫了小隊 → 照 `squad.md` §2 讀小隊的卡。都沒有 → 告訴使用者，問要不要照 §1 建；不要自己猜職責。
2. `office_roster` 看有沒有別人已登記這個角色（職稱＝角色名）且在線 → **停下來問使用者**。兩個 session 不能同時頂同一角色（檢查點會交錯）。
3. 只讀卡上的「必讀」，再讀 `checkpoints/<角色>.md` 的**最後一筆**。不讀 `collab.md`——跟你有關的由主管在報到時回給你。
4. 登記辦公室：`office_profile(title=<角色>, team=<主管的 ListAgents 名稱>)`。
5. 主管在線 → 報到（一則）：
   ```
   接手：<角色>（ListAgents=<你的名稱>）
   上次檢查點：<最後一筆的「下一步」>
   ```
   主管回覆跟你有關的佔用與待裁示，照它做。
6. 回報使用者三行內：接手了什麼、讀了哪些檔、第一件要做的事。

## 4. 檢查點（`checkpoints/<角色>.md`）

做到一個段落、要收工、或上下文快滿要 `/compact` 前存一筆。**只往後加，不改前面的**；只有持有這個角色的 session 寫。

```markdown
## YYYY-MM-DD HH:mm <ListAgents 名稱>
- 做完：一兩行（指 commit 或檔案路徑，不抄內容）
- 卡在：沒有寫「無」
- 下一步：接手的人第一件要做的事
```

接手只讀最後一筆。檔案長了不用清——它不進 git、只有最後一筆會被讀。
